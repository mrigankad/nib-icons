Docs

Nib is a set of 2,196 line icons in 42 categories. Every icon is drawn on a 24 by 24 grid with a single 1.5 stroke, so any two icons sit happily side by side. They are plain SVG with no dependencies.

Getting started

Pick the route that fits your project:

  • Browse and copy. Find an icon on the icon page and press Copy SVG or Copy React.
  • Download everything. nib-icons.zip holds all 2,196 SVG files.
  • Link from a CDN. Every file is served from GitHub through jsDelivr. See below.
  • Clone the repo. git clone https://github.com/mrigankad/nib-icons and use the icons/ folder.

Plain SVG

Each file uses currentColor, so it takes the text colour of whatever it sits in.

<svg xmlns="http://www.w3.org/2000/svg" width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="1.5"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M12 2.5S5 10 5 14.5a7 7 0 0 0 14 0C19 10 12 2.5 12 2.5zM13 9l-3 5h4l-3 5"/>
</svg>

CDN links

Reference any icon by name. Pin a tag in production so icons never change underneath you.

<img src="https://cdn.jsdelivr.net/gh/mrigankad/nib-icons@main/icons/hydro.svg"
     width="24" height="24" alt="">

An image tag cannot inherit colour. If you need the icon to follow your text colour, inline the SVG or use the sprite.

SVG sprite

dist/sprite.svg contains every icon as a <symbol> with the id nib-NAME. Inline it once near the top of the page, then reference icons anywhere.

<svg width="24" height="24"><use href="#nib-search"/></svg>

<!-- or from a file on the same origin -->
<svg width="24" height="24"><use href="/sprite.svg#nib-search"/></svg>

React

Copy React on any icon gives you a ready component that forwards props, so size, colour and class names work as usual.

export function HydroIcon(props) {
  return (
    <svg xmlns="http://www.w3.org/2000/svg" width={24} height={24} viewBox="0 0 24 24"
         fill="none" stroke="currentColor" strokeWidth={1.5}
         strokeLinecap="round" strokeLinejoin="round" {...props}>
      <path d="M12 2.5S5 10 5 14.5a7 7 0 0 0 14 0C19 10 12 2.5 12 2.5zM13 9l-3 5h4l-3 5"/>
    </svg>
  );
}

<HydroIcon width={20} height={20} className="text-blue-600" />

React component pack

Every icon ships as a tree-shakable React component in the @mrigankad/nib-icons-react package. Components are named Nib plus the icon name in PascalCase, forward refs and take size, color and strokeWidth.

npm i @mrigankad/nib-icons-react

import { NibHome, NibSearch } from '@mrigankad/nib-icons-react';

<NibHome />
<NibSearch size={20} color="#1F3FD1" strokeWidth={1.75} />

Prefer plain files? npm i @mrigankad/nib-icons gives you every SVG, the sprite and icons.json.

Vue

Nib is not on npm, so inline the SVG markup in a small component. This one takes size and color props. Swap the path for any icon from the icons/ folder.

<!-- NibIcon.vue -->
<script setup>
defineProps({
  size: { type: [Number, String], default: 24 },
  color: { type: String, default: "currentColor" },
  strokeWidth: { type: [Number, String], default: 1.5 },
});
</script>

<template>
  <svg xmlns="http://www.w3.org/2000/svg" :width="size" :height="size" viewBox="0 0 24 24"
       fill="none" :stroke="color" :stroke-width="strokeWidth"
       stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
    <path d="M12 2.5S5 10 5 14.5a7 7 0 0 0 14 0C19 10 12 2.5 12 2.5zM13 9l-3 5h4l-3 5"/>
  </svg>
</template>

<!-- usage -->
<NibIcon :size="20" color="#1F3FD1" />

Svelte

The same idea works in Svelte. Paste the paths from the SVG file and expose props for size and colour.

<!-- NibIcon.svelte -->
<script>
  export let size = 24;
  export let color = "currentColor";
  export let strokeWidth = 1.5;
</script>

<svg xmlns="http://www.w3.org/2000/svg" width={size} height={size} viewBox="0 0 24 24"
     fill="none" stroke={color} stroke-width={strokeWidth}
     stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
  <path d="M12 2.5S5 10 5 14.5a7 7 0 0 0 14 0C19 10 12 2.5 12 2.5zM13 9l-3 5h4l-3 5"/>
</svg>

<!-- usage -->
<NibIcon size={20} color="#1F3FD1" />

Vanilla JS (fetch and inject)

Fetch the file from the CDN and put the markup in the page. The icon then follows your text colour.

<span class="icon" data-nib="search"></span>

<script>
const CDN = "https://cdn.jsdelivr.net/gh/mrigankad/nib-icons@main/icons/";

document.querySelectorAll("[data-nib]").forEach(async (el) => {
  const res = await fetch(CDN + el.dataset.nib + ".svg");
  if (res.ok) el.innerHTML = await res.text();
});
</script>

Fetched files are cached by the browser, but each icon is still one request. For many icons on one page, use the sprite instead.

Figma and design tools

Nib is plain SVG, so it works in any design tool.

Fastest: drag nib-figma.svg onto your canvas. All 2,196 icons arrive as named layers, grouped by category.

  • Drag and drop. Drag one or more SVG files from the icons/ folder onto your canvas.
  • Import the zip. Download nib-icons.zip, unzip it, then select all the files and drop them in together.
  • Copy and paste. Press Copy SVG on the icon page and paste straight into Figma, Sketch or Penpot.

Each icon arrives as a 24 by 24 frame with strokes, so you can change colour and weight right away. Keep the stroke at 1.5 to match the set.

Styling

Colour

Set color on the icon or any parent. Never set fill, the icons are outlines.

Size

Icons are drawn for 24px and stay crisp at 16, 20, 32 and 48. Below 16px some detailed icons lose clarity; pick a simpler one.

Stroke

1.5 is the house weight. When you scale an icon up, keep the line looking the same with vector-effect: non-scaling-stroke, or lower the stroke width in proportion.

.icon { width: 20px; height: 20px; color: #1F3FD1; }
.icon * { vector-effect: non-scaling-stroke; }

Accessibility

Most icons are decoration. Some carry meaning. Treat them differently.

Decorative icons

If a visible text label sits next to the icon, hide the icon from screen readers.

<button>
  <svg width="20" height="20" aria-hidden="true"><use href="#nib-search"/></svg>
  Search
</button>

Meaningful icons

If the icon is the only thing telling the user what something does, give it a name. Use role="img" with aria-label, or add a <title>.

<button type="button">
  <svg width="20" height="20" role="img" aria-label="Search"><use href="#nib-search"/></svg>
</button>

<svg width="20" height="20" viewBox="0 0 24 24" role="img" aria-labelledby="t1">
  <title id="t1">Search</title>
  ...
</svg>

With an image tag, use the alt attribute. Leave it empty for decoration.

Sizing for small screens

Phones need bigger targets, not necessarily bigger icons.

  • Keep the icon at 20 or 24px and make the tappable area at least 44 by 44px with padding.
  • Avoid going below 16px. Pick a simpler icon if you must.
  • Use whole pixel sizes so the 1.5 stroke stays crisp. Sizes of 16, 20, 24 and 32 work well.
  • Use rem or em so icons scale with the user's font size.
.icon-btn { display: inline-grid; place-items: center; width: 44px; height: 44px; }
.icon-btn svg { width: 1.5rem; height: 1.5rem; }

Guidelines

These are the rules every Nib icon follows. Use them if you draw your own icons to sit alongside the set.

24px grid
2px live padding
1.5px stroke
Roundcaps and joins

Do

Keep shapes inside the 20px live area. Use one continuous stroke where you can. Simplify until the icon reads at 16px.

Don't

Mix filled and outline styles. Add text inside an icon. Use stroke weights other than 1.5. Trace or auto convert photos.

Contributing

Ideas and fixes are welcome. Open an issue with the icon name you want and where you would use it. To submit a drawing, add an SVG to icons/ following the guidelines, add it to icons.json, then run python scripts/build.py to rebuild the site data, sprite and zip.

FAQ

Can I use it commercially?

Yes. Nib is MIT licensed, so you can use it in personal and commercial work.

Do I need attribution?

No. A credit is always appreciated, but it is never required.

Can I request an icon?

Yes. Open a GitHub issue with the icon name and where you would use it.

Why outline only?

One style keeps the set consistent. Outlines also take any colour through currentColor, scale cleanly and stay light. Mixing filled and outline icons makes a UI look uneven.
